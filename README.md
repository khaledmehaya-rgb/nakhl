# نخل

تطبيق ويب لمتابعة حفظ القرآن والنمو والتطعيمات والتطور للأطفال. يعمل على الآيفون بدون إنترنت، وكل البيانات محفوظة على الجوال فقط (لا يوجد سيرفر ولا حسابات).

## الرفع المجاني على GitHub Pages

1. أنشئ حساباً على github.com إن لم يكن لديك.
2. أنشئ مستودعاً جديداً (New repository) باسم `nakhl`.
3. اختر "uploading an existing file" وارفع **كل** ملفات هذا المجلد مع مجلد `icons`.
4. من Settings ← Pages: اختر Branch = `main` والمجلد `/ (root)` ثم Save.
5. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/nakhl/`

> لا تضع ملف `nakhl-start.json` في المستودع، فهو يحتوي بيانات الأطفال والمستودع عام.

## التثبيت على الآيفون

1. افتح الرابط من **Safari**.
2. زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
3. افتح التطبيق من الأيقونة، ثم "استيراد ملف البداية" واختر `nakhl-start.json` (أرسله لها واتساب أو AirDrop واحفظه في الملفات).

## التحديثات

عند تعديل الملفات ورفعها من جديد، يصل التحديث تلقائياً عند فتح التطبيق مع اتصال إنترنت. البيانات لا تتأثر.

## الملفات

- `index.html`, `styles.css`, `app.js` — التطبيق
- `data.js` — السور، جدول التطعيمات، معالم التطور، رؤى المراحل
- `who.json` — جداول منظمة الصحة العالمية (LMS) شهرياً من 0 إلى 19 سنة، مأخوذة من مستودعات WHO الرسمية (anthro و anthroplus)
- `sw.js`, `manifest.webmanifest`, `icons/` — العمل بدون إنترنت والأيقونة
